# CTMC CGI 车载数据服务

线上入口：[quality-ctmc.cloud/vehicle/](https://quality-ctmc.cloud/vehicle/)，也可从质检主页第 05 个业务模块进入。使用现有平台账号；管理员默认新增 vehicle 权限，其他账号由用户管理显式授权。

后续设备工作模式统一采用 **组合 AHRS**（2026-09-03 用户确定）。平台继续按实际 GPCHCX 导航状态与数据质量处理；选择 AHRS 不代表已获得有效组合解。当前核心算法可沿用，实测情况与安装/姿态参考系边界见 [组合 AHRS 适用性评估](docs/组合AHRS适用性评估-20260903.md)。

## 已实现

- GPCHCX 46 字段解析、XOR 校验、十六进制状态/告警、GPS 时间转 UTC，前端统一北京时间。
- SN 自动建档，独立车辆/车队资料、规则和事件。公网 IP 变化不改变设备身份。
- 设备与时间范围查询、高德国内底图（GCJ-02 展示，原始数据 WGS84）、轨迹首尾、回放速度、时间滑块、断档/跳点断线。
- 12 组惯导图表：姿态、三轴角速度、三轴比力、三向速度、位置/姿态/速度标准差、平面速度、高程、卫星数、差分延迟、航迹角。时间缩放与过滤后的有效峰值包络；状态提示值保留，缺测字段不补零。
- 运行总览和惯导分析在速度、俯仰/横滚、水平定位标准差及差分延迟曲线上以橙色虚线标注当前报警阈值；运行总览振动曲线保留 0.80 g 冲击参考线，惯导分析独立展示急加减速变化率和三轴冲击判定曲线，事件峰值保留为证据点，不误画成不相关的水平线。
- 运行总览提供筛选时段 10 Hz 低频振动趋势，并与速度剖面共用时间轴、悬停联动显示速度和振动；短时使用原始显示桶，长时使用 60 秒/10 分钟派生桶，展示动态 RMS、峰值偏差、峰峰值和有效样本数。诊断频谱从筛选时段候选连续窗中选择去趋势动态 RMS 最大的名义 60 秒窗口；惯导分析不重复展示振动模块，不新增振动原始数据落盘。
- 运行总览的“需要关注”和事件页只展示数据质量通过测量上的速度、加速度、俯仰/横滚角、振动值超阈值事件；事件由采样和当前设备规则自动生成，无需维护事件清单。数据本身异常、状态告警、断档和位置跳变统一在数据质量页体现。
- 当前默认阈值策略 v2 为：速度 85 km/h、急加速 14 m/s²、急减速 15 m/s²、俯仰 18°、横滚 20°、振动 0.70 g。该组值依据 CGI-430 测试小车 2026-09-01 11:10:53—2026-09-05 11:10:53 的真实分布校准；策略会自动迁移未自定义的旧默认值，保留自定义设备规则。
- 阈值事件连续合并并定位到有效采样；事件页按每个参数组展示筛选时段内超差幅度 Top10，列表和采样详情同时标出峰值、阈值、超出量及超出比例。历史记录保留规则版本；隔离原值和原始报文核验集中于数据质量页。
- 速度积分估算里程、运动时长、停留/行程区段、固定解占比、有效数据 CSV 导出、接入与磁盘质量面板。
- 独立离线解析工作台：上传与“导出有效数据”同字段的 CSV/CSV.GZ，重建轨迹、行程与停留、阈值事件和 12 组惯导图表；不写入在线采样、设备、事件或审计库。
- 速度口径为 v8 可信地速：`√(Ve²+Vn²) × 3.6`，V_2D 只做同源一致性校验；速度标准差与连续性门控通过后才计入曲线、最大值和里程。持续低速、低不确定度且 IMU 安静才输出静止 0，初始化、纯惯导和证据不足留空；不从漂移坐标算速，匀速不因低振动被归零。页面显示采样覆盖率，原始字段不改。详见 [可信地速算法](docs/可信地速算法.md)。

## 结构

```text
CGI 设备 → 原有 TCP :9000 → 原始日志（原服务完全保留）
                              ↓ 只读增量/游标
                     新车载服务 :8790（仅回环）
                              ↓
                   独立 SQLite WAL 数据库
                              ↓
                  现有 nginx /vehicle/ 路由
                              ↓
                   平台会话 + vehicle 权限
```

`vehicle/protocol.py` 协议；`store.py` 入库、规则、查询；`rules.py` 业务规则判定；`quality.py` 过滤与冻结参考；`server.py` 认证与 HTTP；`static/` 页面；`tests/` 真实报文和合成边界测试；`deploy/` 部署与回滚；`integration/` 现网最小挂载工具。

## 运行与验证

需要 Python 3.11+。服务端无第三方 Python 依赖，前端 Leaflet 1.9.4、ECharts 6.1.0 静态文件已固定版本，许可证保存在 `static/vendor/`；静态文件 SHA-256 记录于 `docs/vendor-manifest.json`。

```bash
python3 -m unittest discover -s tests -v
node --check static/app.js
python3 -m vehicle.server --raw /path/to/raw --db data/vehicle.sqlite --auth http://127.0.0.1:8010
```

实际 API 不提供匿名/测试登录。`tmp/preview.py` 仅为本次本机只读视觉验收，不在部署包内。

## 重要边界

当前实际接入的是 GPCHCX（设备 6094510），GPCHC 基础解析器要求显式设备绑定；无 SN 的基础报文在采集中隔离并统计，不能依公网 IP 自动归属。辅助 ASCII 只核验校验和并计数；未知二进制未解码，原文件仍保存。

SN 是逻辑身份，不是密码鉴权。当前接收器为公网原始 TCP，多设备正式运营应使用专网/VPN或认证网关。默认模块授权可查看所有接入设备；车队字段用于分类，不是租户权限隔离。

原始坐标按 GNSS 默认 WGS84 使用；高德底图覆盖物统一在前端转换为 GCJ-02 展示，数据库保留原始 WGS84，过滤后的导出和里程计算亦使用 WGS84。显示转换不用于厘米级测量。详见 [大陆底图修复](docs/大陆底图修复.md)。加表单位 g、陀螺单位 °/s 依据手册同类 IMU/CAN 定义及实际静态重力量级采用；上线运输业务前应结合设备输出配置和安装标定复核。

地图瓦片使用高德公开道路底图，显示署名并按正常视口加载，无预下载。受外网可用性和服务政策限制；正式规模部署应换为有服务保障的合规地图服务，并继续明确 WGS84 → GCJ-02 只属于显示边界。

本系统为工况分析试运行版，不是 JT/T 808 协议终端或通过 JT/T 796 认证的监管平台。车辆业务阈值是工程起始值，不是法规统一阈值。没有司机身份/CAN/油耗/道路限速输入时，不输出疲劳驾驶、油耗或真实道路违法结论；没有 ISO 2631 频率加权与合适安装条件时，不输出人体振动舒适度等级。

振动分析受 10 Hz 输入的奈奎斯特上限约束，只展示保守的 0–4 Hz 低频载体振动。运行总览振动趋势与速度剖面读取同一筛选边界并联动悬停；诊断 FFT 在筛选时段候选连续窗口中选择去趋势动态 RMS 最大的名义 60 秒原始窗，不由聚合桶重建频谱。缺测、不连续窗口不插值，也不用于轴承、齿轮等通常需要 kHz 级采样的机械故障诊断。设备在 10 Hz 输出时的抗混叠特性尚未由厂家资料或实测确认，因此 FFT 只作趋势观察。三轴合成模长后做线性去趋势可降低安装方向影响，但不等同于已获得车体系线加速度或严格去重力。

图表单次最多查询 31 天：6 小时以内读取原始采样，6 小时至 2 天使用 60 秒派生聚合，2 天以上使用 10 分钟派生聚合，首尾不足一个聚合桶的部分仍读取原始采样。展示桶按时段限制为 420/520/420/320 个，降低筛选后曲线重绘开销；聚合仍保留过滤后均值、最小值、最大值、三轴比力合成模长的 min/max/sum/sum-of-squares/count，以及轨迹断点和运动摘要。每个设备、每个分辨率都必须与设备累计点数一致且版本有效；未就绪时仅在原始数据不超过 100 万条时安全回退，否则明确拒绝。长窗口每个源桶保留首尾轨迹锚点，回放在连续锚点之间做显示插值，原始采样仍是唯一事实来源。按当前约 10 Hz 估算，单设备连续 10 天约 864 万条原始采样，查询只需合并约 1,440 个十分钟桶。持续多车 100 Hz 最终仍应升级分区时序存储和归档任务。已配置每小时容量检查：达到 80% 后按旧到新清理车载原始日志及关联采样和各层聚合，目标降至 75%，保护最近 24 小时及活动文件。详见 [存储清理说明](docs/存储清理说明.md)。

离线解析与在线导出使用同一 CSV 字段契约。单文件只允许一台设备、最长 31 天、最多 3,000 万行；原始 CSV 上限 12 GiB，CSV.GZ 上限 1 GiB。10 天约 864 万行，建议先用 `gzip 原文件.csv` 得到 `.csv.gz` 再上传。服务从 nginx 到 Python 解析器全程流式读取，以最多约 1,600 个自适应源桶控制内存；10 天采用 10 分钟源桶，页面仍输出至多 360 个展示桶并保留各字段最小/最大包络。大文件解析可能持续数分钟，期间不要关闭页面。上传结果只存在于该次响应及当前浏览器页面。
