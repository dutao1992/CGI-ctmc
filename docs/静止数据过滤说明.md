# 运动、静止与异常隔离 v8

当前规则详见 [可信地速算法](可信地速算法.md)。线上/历史重算/离线采用同一个版本化地速投影：导航速度精度与连续性门控、持续低速与 IMU 安静共同证明静止、证据不足留空。0.01 g 不再单独决定运行/静止，V_2D 不再直接作为车辆有效速度。

原始 points 与报文不改写；point_quality 保存字段掩码，point_ground_speed 保存因果地速判定。旧 v1—v4 静止事实仍绑定各自 SN 和范围，保留审计但不自动覆盖后续运动。运行轨迹对新算法确认的连续静止段沿用前后运动位置与导航可信度选出的固定锚点。

## 历史记录的解释边界

下列为当时版本的审计记录，不代表 v8 当前规则或速度结果。低振动本身不能证明导航速度一定来自漂移，单点旧判定不能当作新算法真值。v8 原始全历史回放及外部真值缺口见上方算法说明。

## 2026-08-27 参数设置后的状态快照

截至本次升级前的最新 10 分钟约 6,001 条采样：

- 主要状态为 `91`：卫导模式、RTK 浮点、未定向；短暂出现 `71`、`61` 和 `00`；
- warning 为 `0x0002`，按手册属于 PPS 保留位，不作为已确认硬件故障；
- pitch 中位数约 `0.45°`，roll 中位数约 `-0.25°`；三轴角速度稳定在零附近；
- 速度中位数 `0.05m/s`，但存在约 `1m/s` 静止假速度；位置和高程仍有明显漂移；
- `lat/lon` 标准差中位数约 `3.23/3.56m`，95 分位约 `13.10/12.45m`，定位质量不稳定；
- 尚未出现组合导航状态 `nav_mode=2`，RTK 固定解占比仍为 0%。

因此安装角修正有效，但差分只达到浮点且组合导航未就绪。算法可以阻止漂移污染运行页面，不能替代设备侧完成固定解、定向与组合对准。

## 页面、证据与发布

- 总览与惯导统一显示“可信地速”；无可信证据为缺测，确认静止才为 0。最高值注明有值采样覆盖率，不代表缺测时段的速度。
- 原始 V_2D、Ve/Vn/Vu、标准差、IMU 可在单点原始证据复核；字段隔离不是修改原始值。
- 60/600 秒聚合版本 807，CSV 增加 ground_speed_json，离线不对已过滤值重复估算。新旧版本不得混合。
- 只读审计：`python3 analysis/audit_ground_speed.py --db <数据库路径>`。
- 发布停止解析/API和留存定时器，TCP 9000 接收器不停止；备份、重算 v8、比较原始 SHA256 和 quick_check 后切换 release。
- 失败先用上一 release 重建旧质量/聚合版本，再切回旧服务；不以旧库覆盖新接收报文或用户标注。
- 原有 80%/75%、最近 24 小时保护的容量留存策略不变；到期删除时同事务清理 point_quality 与 point_ground_speed。

验收命令：`python3 -m unittest discover -s tests -v`；`node --test tests/test_map.cjs tests/test_chart_peaks.cjs`。
