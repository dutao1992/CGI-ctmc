# 分级地速 v9

## 数据契约

可信 `speed`、运动状态、最大值、里程和事件口径与 v8 保持不变。新增 `speed_reference`、`speed_reference_low`、`speed_reference_high` 只用于参考曲线。每条采样只能属于可信或参考中的一个等级；聚合桶允许包含来自不同采样的两个等级，分别求均值/极值，不能把两个桶均值混合成可信值。

`GPCHCX.speed`（V_2D）与 `hypot(Ve,Vn)` 是同源导航结果，不能通过加权平均宣称提高独立测量精度。前者保留原始证据及一致性校验，后者供可信值与参考向量计算使用。

## 参考层门槛

- 可信值为空，原因为低信噪比未决或运动预热；当前导航必须通过 v8 全部候选质量门槛。
- 同一导航模式的连续尾窗至少 1 秒、5 个不同时间戳；最长只用过去 2 秒，相邻采样不超过 0.3 秒。坏帧、模式切换和断档都重新积累窗口。
- 分别取 Ve、Vn 的中位数，再求水平模长。不对非负模长直接平滑，避免低速正偏差；不做预测、补零、坐标差分或 IMU 积分。
- 向量残差 MAD × 1.4826 不超过 0.25 m/s。90% 分位残差不得大于 `max(0.3, 3×窗口最大水平标准差)`，避免方向来回翻转时 MAD 退化。当前点与中心也必须一致。
- 参考误差尺度取窗口最大水平标准差与残差尺度的较大者，不除以样本数平方根。包络为 `[max(0, v−3σ), v+3σ]`，属于工程展示包络，**不是经过真值标定的置信区间**。
- 参考值不得改变 `unknown` 状态，不参与最高可信地速、运动时间、里程、告警或静止位置锚点。

## 展示和导出

绿色可信范围/均值与紫色点状参考曲线共用时间轴，缺测不连线。悬停显示参考包络及非可信说明。覆盖率按采样条数分别统计可信、参考与两者之和，不是时间覆盖率；参考增加并不意味着可信最高值覆盖了全程。

在线原始/60 秒/600 秒聚合及离线 CSV 使用相同字段。CSV 通过 `ground_speed_json.reference` 携带参考值、误差、窗口及方法；导入严格校验元数据。v8 CSV 必须重新导出后才能按 v9 离线分析。

## 验收与上线

`tests/test_reference_speed.py` 覆盖低速最小复现、静止/运动互斥、坏导航、52.344 km/h 失真、模式/断档恢复、方向翻转、稀疏回填、三级聚合、CSV 往返与非法元数据。前端测试覆盖分级曲线、参考不挂报警线、缺测不显示 0、不产生伪加减速。

`analysis/audit_reference_speed.py --db ...` 用只读连接逐点回放并比较生产旧可信值/状态/原因；它验证不回归和展示覆盖收益，不验证绝对真实速度。迁移仅更新可重建派生数据，版本 9 / 聚合版本 907。旧 API 在隔离副本计算期间继续提供查询，独立 TCP 接收器不停。预计算限时 40 分钟，最终写入限时 180 秒；失败恢复旧派生表/旧 release，不覆盖原始报文与用户标注。
