NAVIGATION STATUS · 最重要的字段

先看状态：所有测量值的前提

💡 在看任何惯导数值之前，先确认导航状态。状态不对，数值再好看也没意义。

nav_mode · 导航模式（低 4bit）

值含义数据可用性
0初始化中❌ 所有测量不可用
1纯卫导模式位置可用，IMU 辅助有限
2组合导航（最优）✅ 全部字段可信
3纯惯导推算卫星中断，漂移累积

fix_mode · 定位模式（高 4bit）

值含义精度等级
0无定位❌ 位置无效
1/6单点定位±3 m（水平）
2/7伪距差分±1 m（水平）
4RTK 固定解 + 定向±2 cm（水平）
5RTK 浮点解 + 定向±5 cm–10 cm
8RTK 固定解（未定向）±2 cm
RTK 固定解（4/8）是厘米级精度的前提。非固定解时请勿按厘米级解读位置数据。
01 / POSITION

位置与高程：lat / lon / alt

lat · 纬度（°）

是什么：设备所在位置的南北方向坐标，WGS84 椭球体。

能看出什么：设备是否发生了南北位移，结合高德地图轨迹定位车辆路线。

正常范围：中国大陆约 20–53°N。静止时微小漂移（GNSS 精度限制）属正常。

lon · 经度（°）

是什么：设备所在位置的东西方向坐标。

能看出什么：判断车辆是否偏离预期路线，识别绕路或临时停驶。

alt · 高程（m）

是什么：相对于 WGS84 椭球体的高度（不是海拔，略高于实际海拔）。

能看出什么：上坡/下坡趋势；隧道进出时卫星信号中断导致高程跳变；载货后车身下沉（变化量通常 <10 cm）。

INDUSTRY REFERENCE
指标参考标准说明
位置精度RTK 固定：≤ 2 cm + 1 ppmCGI-430 标称
静止漂移上限本平台配置 ≤ 15 m超出判为位置异常
位置跳变本平台判定：超出速度预测 + 20 m记录 position_jump 事件
注意 WGS84 vs GCJ-02：数据库存储 WGS84 原始坐标；高德地图展示时在前端转换为 GCJ-02（国测局坐标）。两套坐标直接叠加会偏移约 100–500 m，切勿混用。
正常特征：静止期位置在 1–5 m 范围内随机漂移，无明显方向性趋势。
02 / ATTITUDE

姿态三角：heading / pitch / roll

车辆坐标系（安装朝向决定轴向）
↑ 北 车辆 → 东
heading: 车头方向，0° = 正北，顺时针增大
pitch: 车头上仰为正，下倾为负
roll: 右倾为正，左倾为负（安装依赖）

heading · 航向角（0–360°）

描述车辆当前朝向哪个方向。需要 nav_mode=2 且 fix_mode ∈ {1,2,3,4,5} 才有意义（双天线定向）。

能看出什么：车辆转弯方向、是否掉头、是否在不应有的方向行驶。

pitch · 俯仰角（-90° ~ +90°）

车头相对于水平面的仰角。正值：爬坡/上坡。负值：下坡。

解读价值：路面坡度、急制动时车头下沉（负 pitch 突增）、车辆是否颠覆（|pitch| > 30° 极端危险）。

行业参考：JT/T 794 未直接规定俯仰阈值，工程经验：正常行驶 |pitch| < 8°；山路可达 15°；超过 20° 建议关注。

roll · 横滚角（-180° ~ +180°）

车辆左右倾斜角度，是侧翻风险最直接的指标。

注意：安装倾斜时静止横滚值不为 0°，需以安装基准值为参考。

行业参考：道路运输危险货物法规关注侧翻，工程经验：|roll| > 10° 告警；|roll| > 15° 紧急；|roll| > 25° 已极度危险。
03 / GYROSCOPE

角速度（陀螺仪）：gx / gy / gz

🔄 是什么

陀螺仪测量车辆绕三个轴的旋转速度，单位 °/s。三个分量分别对应车辆的滚转（gx）、俯仰变化率（gy）、偏转变化率（gz）。

与 roll/pitch/heading 的关系：姿态角是积分结果，角速度是瞬时变化率。

👁️ 能看出什么

  • 急转弯：gz（偏航方向）峰值明显
  • 颠簸/路况：gy（俯仰方向）高频振荡
  • 侧翻前兆：gx（滚转方向）快速增大
  • 陀螺漂移：静止时非零值，是噪声基准

📊 正常静止噪声水平

CGI-430 陀螺零偏稳定性约 0.01–0.1 °/s。静止时各轴应在 ±0.15 °/s 以内（平台使用的工程底线）。

04 / ACCELEROMETER · 最关键的安全指标

比力（加速度）：ax / ay / az

⚠️ 关键概念：比力 ≠ 运动加速度

比力 = 运动加速度 + 重力。静止水平放置时，az ≈ 1g（地球重力），ax ≈ ay ≈ 0。

如果设备安装倾斜（如侧面安装），重力会分量到多个轴，导致静止时某轴不为零，这属于正常现象。

👁️ 能看出什么

  • 急加速：ax（纵向）正向突增
  • 急制动：ax 负向突降（可超过 -0.5 g）
  • 急转弯：ay（横向）偏离基准值
  • 路面颠簸/冲击：az 骤变，合成比力 |√(ax²+ay²+az²) - 1| 超限
  • 侧翻：az 接近 0，ay 接近 ±1 g
SHOCK CALCULATION

🧮 冲击计算公式

平台使用的冲击度量（去除重力基准后的合矢量）：

shock = |√(ax²+ay²+az²) − 1|

扣除 1g 重力后，剩余部分代表纯运动引起的动态冲击力。

05 / VELOCITY

速度字段：speed / ve / vn / vu

speed · 车辆平面速度（m/s，展示转 km/h）

水平合速度 √(ve² + vn²)，GNSS/IMU 融合输出。

能看出什么：超速识别（默认阈值 80 km/h，可调）；行驶/停留状态区分（≥1 m/s = 运动）；急加减速计算（相邻原始采样差值 / 时间间隔）。

重要：速度是 GNSS 多普勒 + IMU 融合，不是轮速，不是 CAN 里程。绝对值可信，但不等于交通执法使用的车速。

ve / vn / vu · 三向速度分量（m/s）

ve：东向速度（正东为正）
vn：北向速度（正北为正）
vu：天向速度（上升为正）

能看出什么：行驶方向分析；vu 反映车辆在垂直方向的状态（上坡/下坡时有小量，静止时应接近 0）。

ACCELERATION DETECTION

🏎️ 急加速 / 急制动检测逻辑

基于 0.8–2.5 秒窗口内相邻原始采样的速度差：

accel = (v_now − v_baseline) / Δt

06 / POSITION UNCERTAINTY

位置不确定度：lat_std / lon_std / alt_std

是什么

设备自报的位置估计误差（标准差，1σ），单位 m。这是系统的自我评估，不是独立测量的实际误差。

  • lat_std：南北方向位置不确定度
  • lon_std：东西方向位置不确定度
  • alt_std：高程不确定度（通常比水平大 1.5–3 倍）

能看出什么

  • 卫星信号是否受遮挡（楼宇峡谷、隧道）
  • RTK 差分质量是否下降
  • 是否处于多路径干扰环境
  • 位置数据可信程度（辅助质量门控决策）
QUALITY THRESHOLDS
定位等级水平 σ 参考典型场景
RTK 固定解< 0.05 m空旷区域、基站信号好
RTK 浮点解0.05–0.5 m信号略有干扰
伪距差分0.5–2 m城市环境
单点定位1–5 m无差分信号
纯惯导推算快速增长无卫星覆盖
平台质量门控：
  • 水平 σ > 2 m：触发 position_std 信息事件
  • 水平 σ > 5 m（静止区段）：判为位置不确定度超限异常
07 / ATTITUDE & VELOCITY UNCERTAINTY

姿态与速度标准差

姿态标准差

heading_std（°）

航向角不确定度。双天线配置下 RTK 固定时可达 0.1° 以内；单天线或定向未就绪时此字段被屏蔽（不展示）。

pitch_std / roll_std（°）

俯仰和横滚角不确定度。组合导航充分收敛后通常 < 0.5°。增大时说明 IMU 与 GNSS 融合质量下降，姿态数据可靠性降低。

速度标准差

ve_std / vn_std / vu_std（m/s）

东/北/天三方向速度分量的不确定度。

  • RTK 固定解时：≈ 0.01–0.05 m/s
  • 伪距差分时：≈ 0.05–0.2 m/s
  • 纯惯导推算时：快速增长
vu_std 通常比水平速度 σ 大 2–3 倍，这是垂向 GNSS 精度结构的正常特征。
如何使用这些标准差

📐 质量决策参考

  • 急加减速事件：检查 lat_std/lon_std 是否在 position_std_m 阈值以内（超出时不生成事件）
  • 横滚/俯仰事件：pitch_std/roll_std 大时参考价值降低
  • 速度积分里程：ve/vn 标准差大时里程精度降低

🔍 诊断用途

标准差随时间异常增大 → 可能存在多路径干扰或卫星几何结构不良（GDOP 劣化）。

08 / GNSS HEALTH

卫星质量指标：sat1 / sat2 / age

sat1 · 主天线使用卫星数

当前参与定位计算的卫星颗数。数量越多，定位几何结构越好，精度越高。

卫星数含义
< 4 颗无法定位（至少需要 4 颗）
4–6 颗勉强定位，精度差
7–10 颗正常定位
≥ 10 颗良好，RTK 条件充足

sat2 · 副天线使用卫星数

双天线架构下副天线的卫星计数，主要用于航向角（heading）计算。副天线卫星少 → heading 精度降低。

age · 差分延迟（s）

当前 GNSS 差分数据的"年龄"——距离最新一次收到差分改正数的时间。

数值含义：

  • age = 0：使用最新差分，定位最优
  • age = 1–5 s：轻微延迟，精度略降
  • age = 5–10 s：延迟明显，接近从差分降级
  • age > 10 s：差分严重滞后，位置精度不可靠
  • age 缺失/跳变：差分信号中断
INDUSTRY REFERENCE
标准/规范差分延迟要求
JT/T 794（部分版本）建议 age ≤ 5 s
本平台工程阈值age > 10 s 触发告警
RTCM 差分协议通常 1 Hz 更新，理想 age < 1 s
09 / COURSE OVER GROUND

航迹角：course / course_std

course · 航迹角（°，0–360）

基于运动轨迹计算出的行驶方向（地速方向）。与 heading 的区别：

  • heading：车头指向（双天线融合，与车辆朝向一致）
  • course：实际移动方向（速度矢量方向，受侧风/侧滑影响可与 heading 不同）
重要限制：速度 < 1 m/s 时 course 值无意义（此时被屏蔽）。静止时 course 不展示。

course_std · 航迹角标准差（°）

航迹角估计的不确定度。低速时 course_std 很大，高速时收敛到 < 1°。

🧭 heading vs course 的差异含义

在理想直线行驶时，heading ≈ course。两者差值（偏流角）有实际意义：

  • |heading - course| < 5°：正常行驶
  • |heading - course| > 10°：可能侧滑、强侧风、转弯过渡段
  • |heading - course| > 30°：异常，检查驾驶状态
航向角 heading 需要双天线定向条件（fix_mode ∈ {1,2,3,4,5} 且 nav_mode=2），否则不可信。平台在条件不满足时自动屏蔽 heading 字段。

11 / STATIONARY BASELINE

静止基线：理解"异常"的前提

📌 为什么静止设备会有"运动数据"

  • GNSS 位置漂移：卫星几何变化导致位置估计随机游走，可达数米
  • 速度残余：静止时速度不严格为零，通常有 0.1–0.5 m/s 噪声
  • 姿态微振：路面振动、风载、温度形变导致 pitch/roll 轻微波动
  • 陀螺零偏：即使静止，角速度仪表也有固定偏置
  • 比力偏置：加速度计有零偏和温漂

⚠️ 读图警示

静止期间显示的"速度"、"位移"、"角速度"都是噪声和漂移，不代表车辆真的在移动。

平台通过"已确认静止"上下文，将这类数据标记并在轨迹地图上隐藏，在异常台账中归类为"静止残差"，不计入行驶里程。

MAD ROBUST BASELINE

🔬 平台如何建立静止基准

用已知静止时段的数据，通过 MAD（中位绝对偏差） 方法拟合基准：

  1. 计算各字段的中位数作为参考中心（抵抗极值污染）
  2. 计算 MAD = median(|xi - 中位数|)
  3. 门槛 = max(工程底线, 6 × 1.4826 × MAD)
  4. 新到采样超出此门槛 → 标记为静止异常

12 / HOW TO READ CHARTS

惯导图表读图指南

🎨 颜色含义

深色粗线：均值（有效采样的平均值）

浅色细线（包络）：min/max 峰值范围，展示变化幅度

菱形散点：已触发的异常事件点位

浅黄色背景区域：数据时间断档区间

空白 ≠ 零：字段被过滤时图表留空，不是补零，不是真实的零值。

📏 时间分辨率

查询窗口数据源
< 6 小时原始采样 ~10 Hz
6h – 2 天60 秒聚合桶
> 2 天10 分钟聚合桶

长窗口图表均值是时段内有效采样的平均，短时冲击仍在 max 包络可见。点击事件菱形点可在地图上定位。

🔎 异常排查流程

  1. 确认 nav_mode / fix_mode 状态是否正常
  2. 查看卫星数和差分延迟是否充足
  3. 检查异常时刻对应的位置标准差
  4. 对照速度剖面判断是否在行驶中
  5. 进入"数据质量"页查原值和过滤原因
  6. 点击"原始报文偏移"追溯到设备发出的字节
