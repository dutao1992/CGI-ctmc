# 可信地速 v8

## 协议与物理含义

依据《CHC CGI-430 厘米级组合导航系统用户手册 V2.4.4》（2025-06-06），印刷页 9—11（PDF 第 13—15 页）：GPCHCX 第 16/17/18 字段为东/北/天向速度，单位 m/s；第 19 字段为 V_2D 车辆平面速度，单位 m/s；第 28/29/30 字段为对应速度标准差，单位 m/s。印刷页 47—48 解释卫导、组合导航、纯惯导和行驶状态；未进入组合导航时设备界面显示“静止”不构成实际停车证据。

`v_h = hypot(Ve, Vn)`，显示单位 `km/h = v_h × 3.6`。不使用三维速度模长，不从经纬度差分求速度，不积分含重力的加速度，也不把 V_2D 和 Ve/Vn 当作两套独立测量。V_2D 只用于检查解码/同源字段一致性。

## 判定流程

实现：`vehicle/ground_speed.py`。只使用当前及此前 2 秒原始数据，无未来信息。

1. 当前导航须是卫导或组合导航（nav_mode 1/2）且有定位；初始化、纯惯导、缺少标准差不输出地速。定向未就绪不单独否决地速，卫导也不冒充 GNSS/INS。
2. 合成不确定度尺度 `sigma_h = hypot(Ve_std, Vn_std)` 不超过 0.5 m/s；分量标准差不得为负。V_2D 与 v_h 的差不超过 `max(0.05 m/s, 1% × v_h)`。
3. 地面载体工程门限：水平速度不超过 130 km/h，垂向速度不超过 `min(5 m/s, max(2 m/s, 0.5 × v_h))`，垂向速度标准差不超过 1 m/s。失败留空，不限幅成边界值。
4. 静止：连续 2 秒（至少 3 个不同采样时刻）所有合格帧 `v_h ≤ 0.15 m/s`、`sigma_h ≤ 0.25 m/s`、三轴比力模长偏差 ≤0.01 g、角速度模长 ≤1°/s，且无加表/陀螺异常位。满足才输出 **0** 和静止状态；已判静止的展示位置用原有跨段固定锚点算法。
5. 运动：连续至少 0.5 秒、至少 3 个时刻速度均超过 0.15 m/s 且超过 3×sigma_h。与之前 0.5 秒速度向量中位数比较，允许差为 `max(0.3 m/s, 3 m/s² × 时间差 + 3 × 合成前后 sigma_h)`；不连续跳变留空。通过则输出当前 v_h，不平滑或削掉合格峰值。
6. 其余为 **未知/缺测**，包括预热和低速与噪声无法区分。采样断档 >1.05 秒重启窗口；当前坏帧不得延用上一好速度。10 Hz 重复的导航解算不会因坐标不变被否决，也不会用重复帧缩小标准差。

以上阈值是可版本化的工程显示策略，不是厂家保证、真值证明或统计置信区间。尤其低速恒定偏差、持续同向多路径可能仍通过；没有轮速/已标定参考仪器，不能恢复全部时段的真实速度。0.01 g 是辅助安静条件，不是“低于即停车”的运动学定律。2026-09-03 用户确定后续统一使用组合 AHRS；该地速算法不依赖车载动态标定，仍要求实际输出有效解，初始化不会因配置为 AHRS 被放行。详见 [组合 AHRS 适用性评估](组合AHRS适用性评估-20260903.md)；本轮未修改设备配置。

## 一致性与保留边界

- `points`、原报文不改写。`point_ground_speed` 独立保存版本、估计、状态、来源、标准差尺度、原因；`point_quality` 保存过滤标记。旧 v1—v4 静止上下文仍仅作审计，不延伸推断未来。
- `quality.project()` 统一服务总览、惯导、单点、事件、里程和 CSV。最高可信地速仅统计有值采样；显示有效采样覆盖率，不称为全程真实最大值。里程仅在两端可信运动且定位连续时梯形积分。
- 60/600 秒聚合版本 807，保留有值采样的 min/max/mean。振动字段/算法不变。不同版本派生桶拒绝混用。
- 迟到帧修复随后 2 秒派生判定和跨分钟桶；重启从原始 2 秒窗口恢复；稀疏重算与完整重算一致。
- 有效 CSV 增加 `ground_speed_json`，离线复用已版本化结果，不从已过滤速度再估算。旧版 CSV 必须重新导出。留存删除同步删除派生地速记录。
